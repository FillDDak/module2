gridclip clipboard capture

A tool for checking gridclip against real applications. Serve the repository root (npm run build && npx http-server .) and open /examples/clipboard-capture.html.

1. Copy a test grid out of gridclip

Click the box and press Ctrl+C (or use the button), then paste into Excel or Google Sheets.

2. Paste from another application

Label: Click the box and press Ctrl+V. Everything the paste event exposes is recorded.
